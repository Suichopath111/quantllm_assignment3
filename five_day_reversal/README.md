# A 股五日反转策略回测

本作业在 [QuantLab 回测系统](https://github.com/Suichopath111/quantllm_assignment2/tree/5ecb553fca0fa7a294b248cb76e55e43c2bf3a5a) 基础上完成。沿用其日频撮合、账户记账和复权估值，增加留存仓位漂移与区间收益输出。回测从 2025 年首个交易日 **2025-01-02** 开始，至 **2026-09-30** 结束，初始资金 **1 亿元**，仅做沪深 A 股多头。

## 标准因子与微调

标准五日反转得分为 `-(复权收盘价[t] / 复权收盘价[t-5] - 1)`。得分越高，代表过去五个交易日跌幅越大。使用前一交易日收盘后的信号，于下一交易日开盘撮合。

作业提交配置为 **T20_N2000_C10**：在每日合资格池内，按五日反转得分降序取平均名次百分位，剔除排名最靠前的 20%，再从剩余股票中按原始得分选最多 2000 只。这样保留反转排序，同时避开跌幅最极端的一档。每隔 10 个交易日检查一次名单；留存股不强制重新等权，新成员的名义资金预算为当日开盘权益的 1/2000，按实际现金与成交约束执行。因子观察窗口仍为 5 日。

## ST、停牌和涨跌停

- **ST 筛选**：按历史逐日状态排除 ST／*ST，状态未知的股票不新买。信号日要求股票正常交易、五日窗口价格完整、有正成交额且至少有 60 条历史收盘记录；执行日再次检查买入资格。持仓转为 ST 后，在调仓检查时尝试退出。
- **涨跌停与停牌**：开盘涨停不买，开盘跌停不卖；停牌或无有效开盘价不成交。受阻卖单保留原持仓，下一次调仓时重新评估；受阻买单的未用资金留在现金账户。涨跌停价按板块规则和复权调整后的前收盘价推算。
- **资金与费用**：先卖后买，遵守 T+1 和买入整手规则，单股成交额受前一交易日成交额 1% 限制。佣金万三、每单最低 5 元，卖方印花税万五，双边过户费十万分之一，每边滑点 10 bp。期末按收盘估值。

## 复现

在仓库根目录安装依赖。准备 QuantLab 使用的六张 Feather 行情宽表（`open`、`close`、`high`、`low`、`cumadj`、`amt`，均有 `date` 列），以及历史状态表 `historical_status.parquet` 和预热补充表 `status_warmup_2024.parquet`。状态表使用 `date`、`symbol`、`isST`、`tradestatus` 和可选的 `delisted` 字段；状态来自 RQAlpha 历史数据包和 BaoStock 交叉整理。2024 年下半年用于信号和历史长度预热，不计入账户收益。

```sh
python -m pip install -r five_day_reversal/requirements.txt
python five_day_reversal/run.py --data PATH_TO_FEATHERS --status PATH_TO_HISTORICAL_STATUS --warmup-status PATH_TO_WARMUP_STATUS --period full
```

把 `--period full` 改为 `--period 2025` 或 `--period 2026` 可独立复算相应年份；加 `--baseline` 则取消截尾，保留其他配置和撮合条件。使用 `--output PATH_TO_JSON` 可保存区间结果。
